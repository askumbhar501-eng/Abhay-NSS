# AquaSentinel AI

AI-powered water quality monitoring and analysis platform.

## Project Structure

- `app/` - Core application logic, API routes, services, and data storage
- `dashboard/` - Frontend visualization and dashboard interfaces
- `data/` - Datasets and data management
- `notebooks/` - Research and exploratory data analysis notebooks
- `simulator/` - Sensor simulation and environment modeling
- `tests/` - Test suites
